# 演示 Runbook（XDWe + DeepSeek Agent / 智能 UI）

> 目标：5 分钟内稳定展示「快答/深度切换 + 工具检索 + 卡片化回答 + 教师权威答案回流」。
> 前置：本机已安装 Python 3.10+、Node.js 20.19+，并有可用 DeepSeek API Key。

## 1. 一次性准备

```bash
# 后端依赖
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r ../requirements.txt

# 配置 Key（.env 不入库）
cp ../.env.example ../.env
#   编辑 .env：DEEPSEEK_API_KEY=sk-xxxx

# 构建知识库索引（卡片里的资料引用依赖它）
python build_index.py --query 二分查找

# 冒烟（不需要启动 Flask）
python smoke_deepseek.py     # 文本流式
python smoke_agent.py        # 深度 Agent + 卡片

# 离线测试
PYTHONPATH=. python -m unittest discover -s tests -v
```

```bash
# 前端依赖与构建检查
cd ../frontend
npm ci
npm run build
```

## 2. 启动

```bash
# 终端 A
cd backend && source .venv/bin/activate && python main.py     # http://127.0.0.1:5000

# 终端 B
cd frontend && npm run dev                                     # http://127.0.0.1:5173
```

浏览器打开 <http://127.0.0.1:5173>，注册两个账号：

- 学生账号（注册页默认学生）；
- 教师账号（注册页选择「教师」）。
- 密码需满足：≥8 位，含大写、小写、数字（页面当前不会提示，提前准备好）。

## 3. 演示数据预热（建议演示前 10 分钟做）

1. 用学生账号在**深度模式**依次问 2–3 个问题（生成历史记录与卡片效果），例如：
   - 「二分查找的时间复杂度怎么推导？」
   - 「动态规划解题的一般步骤是什么？」
2. 用教师账号打开教师端 → 学情分析（首次会实时生成，预热后缓存 24 小时）；
3. 教师端把其中一条问题设为**权威答案**（写一句标准结论）；
4. 回到学生端，用**近义问法**再问一次同一问题，确认回答里带出教师权威内容。

## 4. 演示脚本（约 5 分钟）

| 步骤 | 操作 | 讲解要点 |
|---|---|---|
| 1 | 学生端问「二分查找的时间复杂度怎么推导？」，先用**快答** | 快答一次模型请求，无工具与卡片，速度快 |
| 2 | 切到**深度**，重问同一问题 | 观察「执行过程」出现检索工具；回答下方出现工具轨迹 |
| 3 | 指卡片：参考资料 / 解题步骤 / 相关章节 | 引用编号来自本轮检索；步骤可展开、勾选、每步有依据 |
| 4 | 点某一步「追问这一步」 | 自动带入上下文继续追问，形成多轮学习体验 |
| 5 | 教师端展示学情分析、权威答案回流 | 教师答案经词法匹配注入后续回答 |
| 6 | （可选）上传一张习题图片 | 图片问答走 DeepSeek 视觉 + 快答兜底 |

## 5. 失败兜底

| 现象 | 处理 |
|---|---|
| 断网 / 无法访问 DeepSeek | 切手机热点；仍失败则播放预录屏、展示截图 |
| 回答报「认证失败/余额不足」 | 检查 `.env` 的 `DEEPSEEK_API_KEY`；换备用 Key；充值 |
| 回答超时 | 重试一次；把问题问得更短；演示前预热 |
| 卡片不出现 | 不代表故障：文字回答仍完整；可换演示题（见 `DEMO_QA.md`），或说明模型判断无需卡片 |
| 「未找到 BM25 索引」日志 | 在 backend 目录运行 `python build_index.py` 后重启后端 |
| 教师页学情分析慢 | 属首次生成，预热过即可；或先展示已有学生的提问列表 |
| 服务起不来 | 查看终端报错；确认未把 `.env` 提交、Key 正确、端口 5000 未被占用 |

## 6. 演示前 10 分钟检查清单

- [ ] `.env` 已配置 Key，`smoke_deepseek.py` 通过；
- [ ] `backend/bm25_index/index.json` 存在，启动日志出现「BM25 索引加载」；
- [ ] `smoke_agent.py` 能生成至少 1 张卡片（若网络波动可接受纯文字）；
- [ ] 教师/学生账号可登录；学情分析已预热；
- [ ] 前端 5173 可打开，浏览过一次深度问答；
- [ ] 断网兜底材料（录屏/截图）已就绪。
